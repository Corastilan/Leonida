# Leonida

A fan-made PC recompilation of GTA VI, built for Leonida's native 4K / 120Hz experience.

## Features
- Native PC port with RAGE source restore
- Open-world streaming, ray tracing, and DLSS support
- Full keyboard/mouse, controller, and ultrawide support
- Mod support via `.leonidamod` packages

## Requirements
- Windows 10/11 64-bit
- 16GB RAM, 80GB SSD
- RTX 3060 / RX 6700 XT or better

## Install
1. Download the latest release
2. Verify your game files
3. Run `leonida.exe`
